# 视频下载工具箱

四合一视频下载 / 直播录制工具集，合并自四个既有项目，**开箱即用**（自带运行时，无需 pip install）。

## 快速开始

**双击 `启动工具箱.bat`** —— 统一菜单里点按钮使用全部功能。

| 你想做什么 | 用哪个 |
|---|---|
| 下载抖音视频/图集（粘链接即可） | 菜单 → 抖音下载器 |
| 浏览器界面管理抖音下载 | 菜单 → 抖音 WebUI |
| 下载快手主页作品（粘分享链接） | 菜单 → 快手一键下载器 |
| 快手登录态过期 | 菜单 → 快手扫码登录 |
| 下载任意 http/https 直链文件 | 菜单 → 直链下载 |
| **快手/抖音直播自动录制**（开播即录、断流重连） | 菜单 → 直播录制器 |
| **录不到指定的快手主播** | 菜单 → 直播扫码登录（登录后才能按房间查询） |
| 录制不工作，想查原因 | 菜单 → 直播录制环境自检 |

四个模块也可用项目根的 `启动抖音下载器.bat` / `启动快手一键下载器.bat` / `启动程序下载.bat` / `启动直播录制器.bat` 单独启动。

> 直播录制的录像文件默认保存到 `C:\Users\Mechrevo\LiveRecorder`（按 `平台\昵称\日期` 三级分类），
> 可在「直播录制器 → 设置 → 录制」里改成任意目录；菜单里的「打开录像目录」按钮会跟着这个设置走。

## 目录一览

```
启动工具箱.bat        ← 主入口
toolbox.py            ← 统一菜单程序
modules\              ← 代码（douyin / kuaishou / clawfetch / live_recorder）
runtime\              ← 自带运行时（三个 venv + 快手登录态）
data\                 ← 台账/数据库/作品清单
downloads\            ← 下载产物
docs\                 ← 交接文档
tests\selftest.py     ← 环境自检（python tests\selftest.py）
```
