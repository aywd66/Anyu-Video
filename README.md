# 视频下载工具箱

三合一视频下载工具集，合并自三个既有项目，**开箱即用**（自带运行时，无需 pip install）。

## 快速开始

**双击 `启动工具箱.bat`** —— 统一菜单里点按钮使用全部功能。

| 你想做什么 | 用哪个 |
|---|---|
| 下载抖音视频/图集（粘链接即可） | 菜单 → 抖音下载器 |
| 浏览器界面管理抖音下载 | 菜单 → 抖音 WebUI |
| 下载快手主页作品（粘分享链接） | 菜单 → 快手一键下载器 |
| 快手登录态过期 | 菜单 → 快手扫码登录 |
| 下载任意 http/https 直链文件 | 菜单 → 直链下载 |

三个模块也可用项目根的 `启动抖音下载器.bat` / `启动快手一键下载器.bat` / `启动程序下载.bat` 单独启动。

## 目录一览

```
启动工具箱.bat        ← 主入口
toolbox.py            ← 统一菜单程序
modules\              ← 代码（douyin / kuaishou / clawfetch）
runtime\              ← 自带运行时（两个 venv + 快手登录态）
data\                 ← 台账/数据库/作品清单
downloads\            ← 下载产物
docs\                 ← 交接文档
tests\selftest.py     ← 环境自检（python tests\selftest.py）
```
