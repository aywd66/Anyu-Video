# 视频下载工具箱

四合一视频下载 / 直播录制工具集，合并自四个既有项目，**开箱即用**（自带运行时，无需 pip install）。

## 快速开始

**双击 `启动工具箱.vbs`** —— 统一菜单里点按钮使用全部功能，**全程不出现黑色终端窗口**。

> **两个入口怎么选？**
> - `启动工具箱.vbs` —— 日常用这个。由 wscript 执行，本身不创建控制台，
>   再以隐藏方式拉起 `pythonw.exe`，**零闪烁、零黑窗口**。
> - `启动工具箱.bat` —— 备用/排错用。`.bat` 由 cmd.exe 执行，启动瞬间**必定闪一下黑窗口**
>   （这是 `.bat` 的固有限制，脚本内部怎么写都消不掉）。它的价值在于**报错可见**：
>   万一 `toolbox.py` 有语法错误，它会自动回落到控制台模式把 traceback 打出来，
>   而无窗口启动在这种情况下是没有任何提示的。
>
> 两个入口选用的解释器顺序完全一致：抖音运行时 → 快手运行时 → 直播录制运行时 → 系统 PATH。

| 你想做什么 | 用哪个 |
|---|---|
| 下载抖音视频/图集（粘链接即可） | 菜单 → 抖音下载器 |
| 浏览器界面管理抖音下载 | 菜单 → 抖音 WebUI |
| 下载快手主页作品（粘分享链接） | 菜单 → 快手一键下载器 |
| 快手登录态过期 | 菜单 → 快手扫码登录 |
| 下载任意 http/https 直链文件 | 菜单 → 直链下载 |
| **快手/抖音直播自动录制**（开播即录、断流重连） | 菜单 → 直播录制器 |
| **录不到指定的快手主播** | 菜单 → 直播扫码登录（登录后才能按房间查询） |
| 录制不工作，想查原因 | 菜单 → 直播录制环境自检 |

四个模块也可用项目根的 `启动抖音下载器.bat` / `启动快手一键下载器.bat` / `启动程序下载.bat` / `启动直播录制器.bat` 单独启动。

> **哪里还会看到终端窗口？**
> 从**工具箱菜单**里点任意按钮启动模块，都**不会**出现终端：子进程以隐藏窗口方式拉起，
> 输出统一送进界面下方的日志窗格。只有直接双击 `启动抖音下载器.bat` / `启动程序下载.bat`
> 这两个**命令行工具**时才会看到终端——那是它们自身的运行界面（要显示下载进度），
> 任务结束会自动关闭。`启动快手一键下载器.bat` 与 `启动直播录制器.bat` 是图形程序，不显示终端。

> 直播录制的录像文件保存在 `downloads\live_recorder\`（按 `平台\昵称\日期` 三级分类），
> 与其它三个模块的产物位置统一；可在「直播录制器 → 设置 → 录制」里改成任意目录，
> 菜单里的「打开录像目录」按钮会跟着这个设置走（实时读配置，不写死）。

## 目录一览

```
启动工具箱.vbs        ← 主入口（wscript + pythonw，无窗口，推荐）
启动工具箱.bat        ← 备用入口（会闪一下，但能把报错显示出来）
toolbox.py            ← 统一菜单程序
modules\              ← 代码（douyin / kuaishou / clawfetch / live_recorder）
runtime\              ← 自带运行时（三个 venv + 快手登录态）
data\                 ← 台账/数据库/作品清单
downloads\            ← 下载产物
docs\                 ← 交接文档
tests\selftest.py     ← 环境自检（python tests\selftest.py）
```
