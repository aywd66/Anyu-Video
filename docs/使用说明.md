# 使用说明 — 视频下载工具箱

> 一句话：双击 `启动工具箱.bat`，菜单里点按钮用功能。三个模块互相独立，也可单独启动。

## 0. 首次使用（30 秒）

1. 双击 `启动工具箱.bat`（在 `C:\Users\Mechrevo\Desktop\视频下载工具箱\`）。
2. 弹出「视频下载工具箱」窗口，左侧按钮区自上而下就是全部功能；右侧显示运行日志。
3. 首次启动会自动做环境自检（三个模块 OK/缺失一目了然）。
4. 不需要安装任何东西；如需下载视频，确保网络可访问对应平台。

## 1. 抖音高清下载器（模块 1）

### 界面按钮
| 按钮 | 作用 | 何时用 |
|---|---|---|
| ▶ 抖音下载器（交互命令行） | 弹出控制台，粘贴抖音链接或分享口令后回车，可连贴多个 | 日常下载视频/图集 |
| ▶ 抖音 WebUI（浏览器界面） | 启动本地网页（127.0.0.1:8518）并自动开浏览器 | 喜欢图形界面、查下载历史 |
| 打开抖音下载目录 | 打开 `downloads\douyin\` | 找下载的文件 |

### 命令行直用（进阶）
```powershell
cd "C:\Users\Mechrevo\Desktop\视频下载工具箱\modules\douyin"
..\..\runtime\douyin-venv\Scripts\python.exe launcher.py          # 交互模式
..\..\runtime\douyin-venv\Scripts\python.exe run.py -u "https://www.douyin.com/video/xxxx"   # 直下
..\..\runtime\douyin-venv\Scripts\python.exe run.py --hot-board 5    # 热榜前5
..\..\runtime\douyin-venv\Scripts\python.exe run.py --serve          # REST API
```

### 登录与风控
- Cookie 已随项目迁移。出现"登录态失效/需要重新登录"提示时，在交互模式里按提示重新登录一次即可。
- 实测（2026-09-21）：热榜拉取正常；部分视频详情接口被平台按 `filter_reason=core_dep` 过滤（登录态被降权时的平台侧行为，原项目同样如此）。**解决：重新登录刷新 Cookie 后再试。**

## 2. 快手主页测试下载（模块 2）

### 界面按钮
| 按钮 | 作用 | 何时用 |
|---|---|---|
| ▶ 快手一键下载器（图形窗口） | 弹窗粘贴快手分享链接（v.kuaishou.com/...），选"全部作品/仅最新 1 个" | 日常使用，推荐 |
| ▶ 快手扫码登录（刷新登录态） | 弹出 Edge 窗口扫码，刷新 Cookie | 提示登录态失效/需要下载未公开作品时 |
| 打开快手下载目录 | 打开 `data\kuaishou\`（按作者分文件夹） | 找下载的文件 |

### 一键下载器工作流程（自动完成，无需干预）
解析链接 → 提取作者与作品列表 → 检查登录态（无登录自动弹扫码窗）→ 滚动收集全量作品 → 预取直链 → 多线程下载 → 台账去重 → 完成弹窗并打开文件夹。

### 命令行直用（进阶）
```powershell
cd "C:\Users\Mechrevo\Desktop\视频下载工具箱\modules\kuaishou\tools"
..\..\..\runtime\kuaishou-env\Scripts\python.exe kuaishou_fast_dl.py "..\..\..\data\kuaishou" --workers 4
..\..\..\runtime\kuaishou-env\Scripts\python.exe kuaishou_dl.py "https://v.kuaishou.com/xxxx" "..\..\..\data\kuaishou" all
```

### 实测参考（2026-09-21）
- 登录态迁移后有效：Cookie 注入 11 项（passToken/userId 命中）。
- 真实下载 1 个作品成功：720p 1280x720 2440kbps，14.7 秒，ffprobe 校验完整（46.57s / 14,204,590 字节）。
- 台账去重生效：旧清单 247 个作品全部识别为"已下载"，不重复下载。
- 出现 `Need captcha` = 快手风控，等几分钟再试；`status_1040` = 作品不可访问，自动跳过。

## 3. 程序下载 / clawfetch 直链下载器（模块 3）

### 界面按钮
| 按钮 | 作用 |
|---|---|
| ▶ 直链下载（输入链接） | 输入 http/https 直链（或中转页链接），下载到 `downloads\direct\`，自动重试/续传/SHA-256 校验 |
| ▶ 直链解析（只解析不下载） | 输出真实直链、文件名、大小、是否支持续传；结果可粘到 IDM/aria2 |
| 打开直链下载目录 | 打开 `downloads\direct\` |

### 命令行直用（进阶）
```powershell
cd "C:\Users\Mechrevo\Desktop\视频下载工具箱\modules\clawfetch"
python clawfetch.py "https://example.com/file.zip" -o "..\..\downloads\direct"
python clawfetch.py "链接1" "链接2" -j 2     # 多链接并行
python clawfetch.py "链接" --resolve --json  # 只解析
python clawfetch.py --help                    # 全部参数
```

### 退出码速查
0 成功 | 2 参数错误 | 3 无效链接 | 4 连接失败 | 5 HTTP 错误 | 6 超时 | 7 校验失败 | 8 磁盘错误 | 130 用户中断（重跑同命令自动续传）

完整参数/台账/FAQ 见 `modules\clawfetch\README.md`。

## 4. 常见问题

| 现象 | 处理 |
|---|---|
| 双击 bat 闪退 | 右键"在终端中打开"运行 bat 看报错；确认杀毒软件未拦截 `runtime\` 下的 python |
| 快手下载要求登录 | 点「快手扫码登录」按钮重新扫码 |
| 抖音提示登录态失效 | 在交互模式重新登录；或手动更新 `modules\douyin\.cookies.json` |
| 想换下载保存位置 | 下载按钮产物固定在项目内 `downloads\`/`data\`；进阶用户用命令行 `-o` 参数自定义 |
| 磁盘清理 | `downloads\`、`data\kuaishou\` 下视频均可按需删除；台账删除后会重新全量下载（慎删） |

## 5. 卸载 / 回滚

见《备份与回滚说明.md》。一句话：删除整个"视频下载工具箱"文件夹即完全卸载；三个原项目目录未做任何改动。
