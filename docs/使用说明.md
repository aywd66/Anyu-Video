# 使用说明 — 视频下载工具箱

> 一句话：双击 `启动工具箱.bat`，菜单里点按钮用功能。四个模块互相独立，也可单独启动。

## 0. 首次使用（30 秒）

1. 双击 `启动工具箱.bat`（在 `C:\Users\Mechrevo\Desktop\视频下载工具箱\`）。
2. 弹出「视频下载工具箱」窗口，左侧按模块分成两列按钮区，自上而下/自左至右就是全部功能；右侧显示运行日志。
3. 首次启动会自动做环境自检（四个模块 OK/缺失一目了然）。
4. 不需要安装任何东西；如需下载视频，确保网络可访问对应平台。

## 1. 抖音高清下载器（模块 1）

### 界面按钮
| 按钮 | 作用 | 何时用 |
|---|---|---|
| ▶ 抖音下载器（交互命令行） | 弹出控制台，粘贴抖音链接或分享口令后回车，可连贴多个 | 日常下载视频/图集 |
| ▶ 抖音 WebUI（浏览器界面） | 启动本地网页（127.0.0.1:8518）并自动开浏览器 | 喜欢图形界面、查下载历史 |
| 打开抖音下载目录 | 打开 `downloads\douyin\` | 找下载的文件 |

### 命令行直用（进阶）
```powershell
cd "C:\Users\Mechrevo\Desktop\视频下载工具箱\modules\douyin"
..\..\runtime\douyin-venv\Scripts\python.exe launcher.py          # 交互模式
..\..\runtime\douyin-venv\Scripts\python.exe run.py -u "https://www.douyin.com/video/xxxx"   # 直下
..\..\runtime\douyin-venv\Scripts\python.exe run.py --hot-board 5    # 热榜前5
..\..\runtime\douyin-venv\Scripts\python.exe run.py --serve          # REST API
```

### 登录与风控
- Cookie 已随项目迁移。出现"登录态失效/需要重新登录"提示时，在交互模式里按提示重新登录一次即可。
- 实测（2026-09-21）：热榜拉取正常；部分视频详情接口被平台按 `filter_reason=core_dep` 过滤（登录态被降权时的平台侧行为，原项目同样如此）。**解决：重新登录刷新 Cookie 后再试。**

## 2. 快手主页测试下载（模块 2）

### 界面按钮
| 按钮 | 作用 | 何时用 |
|---|---|---|
| ▶ 快手一键下载器（图形窗口） | 弹窗粘贴快手分享链接（v.kuaishou.com/...），选"全部作品/仅最新 1 个" | 日常使用，推荐 |
| ▶ 快手扫码登录（刷新登录态） | 弹出 Edge 窗口扫码，刷新 Cookie | 提示登录态失效/需要下载未公开作品时 |
| 打开快手下载目录 | 打开 `data\kuaishou\`（按作者分文件夹） | 找下载的文件 |

### 一键下载器工作流程（自动完成，无需干预）
解析链接 → 提取作者与作品列表 → 检查登录态（无登录自动弹扫码窗）→ 滚动收集全量作品 → 预取直链 → 多线程下载 → 台账去重 → 完成弹窗并打开文件夹。

### 命令行直用（进阶）
```powershell
cd "C:\Users\Mechrevo\Desktop\视频下载工具箱\modules\kuaishou\tools"
..\..\..\runtime\kuaishou-env\Scripts\python.exe kuaishou_fast_dl.py "..\..\..\data\kuaishou" --workers 4
..\..\..\runtime\kuaishou-env\Scripts\python.exe kuaishou_dl.py "https://v.kuaishou.com/xxxx" "..\..\..\data\kuaishou" all
```

### 实测参考（2026-09-21）
- 登录态迁移后有效：Cookie 注入 11 项（passToken/userId 命中）。
- 真实下载 1 个作品成功：720p 1280x720 2440kbps，14.7 秒，ffprobe 校验完整（46.57s / 14,204,590 字节）。
- 台账去重生效：旧清单 247 个作品全部识别为"已下载"，不重复下载。
- 出现 `Need captcha` = 快手风控，等几分钟再试；`status_1040` = 作品不可访问，自动跳过。

## 4. 直播自动录制（模块 4）

监控快手/抖音直播间，**开播后自动开始录制**，断流 15 秒自动重连，下播后自动合并成完整文件。

### 界面按钮
| 按钮 | 作用 | 何时用 |
|---|---|---|
| ▶ 直播录制器（图形窗口） | 打开录制器主界面（添加/管理监控房间、看状态与日志） | 日常使用 |
| ▶ 直播扫码登录（快手/抖音） | 弹出浏览器扫码登录，凭证写入模块配置 | **录不到指定的快手主播时** |
| 🔍 直播录制环境自检 | 无界面检查依赖/ffmpeg/配置/解析层 | 录制不工作时**先跑这个** |
| 打开录像目录 | 打开录像根目录（按 `平台\昵称\日期` 分类） | 找录好的文件 |

### 第一次用，按这个顺序
1. 点「▶ 直播录制器（图形窗口）」打开界面。
2. 点界面工具栏「添加直播间」，把链接粘进去（每行一条，快手/抖音分享链都支持）。
   - 取链接：快手 App → 进直播间 → 分享 → 复制链接（形如 `v.kuaishou.com/xxxx`）；抖音同理（`v.douyin.com/xxxx`）。
3. 点「开始监控」。程序按设定间隔（默认 60 秒）轮询开播状态，**开播即自动录制**，下播自动收尾。
4. 想稳定录到**你指定的**主播，先点菜单里的「直播扫码登录（快手/抖音）」登录一次（原因见下）。

### 录像文件在哪、长什么样
- 根目录：`downloads\live_recorder\`（即工具箱内的 `downloads\live_recorder`）
  （可在「直播录制器 → 设置 → 录制」里改；菜单的「打开录像目录」会跟着变）
- 三级分类：`平台\昵称\日期\`
- 文件名：`{平台}_{昵称}_{YYYYMMDD_HHMMSS}_{分段序号}.flv`
- 实例：`快手_传奇妮轩_20260923_190343_001.flv`
- 单场超过 4GB（可调）或到时长上限会**自动分卷**，结束后**无损合并**（`-c copy`，不重新编码）

### 命令行直用（进阶）
```powershell
cd "C:\Users\Mechrevo\Desktop\视频下载工具箱\modules\live_recorder"
..\..\runtime\live-recorder-env\Scripts\python.exe main.py              # 启动界面
..\..\runtime\live-recorder-env\Scripts\python.exe main.py --selftest   # 环境自检
..\..\runtime\live-recorder-env\Scripts\python.exe main.py --version    # 版本号
..\..\runtime\live-recorder-env\Scripts\python.exe login.py kuaishou    # 只登录快手
```
也可双击模块内的 `start.bat` / `login.bat` / `selftest.bat`（会自动找到工具箱的运行时）。

### 为什么快手必须登录
快手网页端对**未登录访客**关闭了「按房间查询」的接口（固定返回占位响应），
并对自动化访问以「请求过快」拦截——实测无头 Chromium、有头 Chromium、有头真实 Chrome
三者**全部**被拦截，说明这不是浏览器指纹问题，而是访客级限制。
未登录时程序只能用**推荐流索引**兜底，只能录到「恰好被推荐到」的房间
（默认拉 3 页 ≈ 30 个房间，可在「设置 → 账号」调大，最多 10 页）。
**登录一次即可监控任意指定主播。** 抖音目前无需登录。

### 常用限制与提示
| 现象 | 说明 / 处理 |
|---|---|
| 快手录到的是别人的直播 | 处于未登录状态，只能靠推荐流兜底 → 点「直播扫码登录（快手/抖音）」 |
| 提示「请求过快 / 风控」 | 快手访客级限制，登录后消失；也可在设置里把「检查并发数」调小 |
| 磁盘剩余 < 10GB | 程序自动暂停全部录制（阈值可在「设置 → 录制」改） |
| 想同时录很多房间 | 「设置 → 录制 → 同时录制数」有上限（默认 8），注意带宽与磁盘 |
| 某个房间显示「未知」而非「未开播」 | 该房间刚开播、还没进推荐流。这是刻意的保守判定，避免把「没查到」误报成「没开播」 |

完整使用说明见 `modules\live_recorder\README.md`；架构设计与排查流程见 `modules\live_recorder\ARCHITECTURE.md`。

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| 双击 bat 闪退 | 右键"在终端中打开"运行 bat 看报错；确认杀毒软件未拦截 `runtime\` 下的 python |
| 快手下载要求登录 | 点「快手扫码登录」按钮重新扫码 |
| 抖音提示登录态失效 | 在交互模式重新登录；或手动更新 `modules\douyin\.cookies.json` |
| 直播录制没反应 / 录不出文件 | 先点「🔍 直播录制环境自检」看哪一项不过；再点「▶ 直播扫码登录」刷新快手登录态 |
| 想换下载保存位置 | 下载按钮产物固定在项目内 `downloads\`/`data\`；进阶用户用命令行 `-o` 参数自定义 |
| 想换直播录像位置 | 「直播录制器 → 设置 → 录制 → 保存目录」直接改；旧录像不会自动搬迁 |
| 磁盘清理 | `downloads\`、`data\kuaishou\` 下视频均可按需删除；台账删除后会重新全量下载（慎删）。直播录像在 `downloads\live_recorder\`，按 `平台\昵称\日期` 目录删即可 |

## 6. 卸载 / 回滚

见《备份与回滚说明.md》。一句话：删除整个"视频下载工具箱"文件夹即完全卸载；工作区那份 `live_recorder\` 已收敛为只读代码快照，不含运行时。
⚠️ **注意：直播录像现在存放在工具箱内的 `downloads\live_recorder\`**——删工具箱会**连带删掉录像**，
需要保留的话先把 `downloads\live_recorder` 拷出来。
