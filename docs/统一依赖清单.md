# 统一依赖清单

> 合并后全项目只有两份运行时依赖清单（对应两个隔离 venv）+ 一份零依赖模块。
> 本清单与实际环境逐包核对过（2026-09-21 自检 17/17 通过）。

## 一、总览

| 模块 | 依赖策略 | 清单来源 |
|---|---|---|
| modules\clawfetch | **零第三方依赖**（纯 Python 3.8+ 标准库） | 无需清单 |
| modules\douyin + runtime\douyin-venv | venv 内已装齐，无需再装 | 原项目 requirements.txt（已满足） |
| modules\kuaishou + runtime\kuaishou-env | venv 内已装齐，无需再装 | 原环境实际包（下表） |
| 统一入口 toolbox.py | 仅 tkinter（两个 venv 自带，Tk 8.6 已验证） | 无需清单 |

**结论：合并后不需要执行任何 `pip install`。** 两个 venv 通过复制原环境完整保留（含 yt-dlp 源码级安装）。
